# 预设头像包

本目录存放用户可选的预设头像图片。搜集后把图片文件放进此目录即可。

## 分辨率与格式要求

| 项目 | 要求 |
|------|------|
| 尺寸 | **256 × 256 px，正方形**（必须 1:1） |
| 格式 | **PNG**（带透明背景）或 **WebP**（体积更小） |
| 文件大小 | 单个 ≤ 200 KB |
| 背景 | 推荐透明背景 PNG，与游戏深色主题适配 |

> 256×256 是首选：座位面板显示约 2rem（~32px），列表缩略图更小，原图需足够锐利；同时不宜过大以免撑大客户端 bundle。如果手头素材是其他正方形尺寸（如 128/512），也可放入，但优先 256。

## 文件命名规则

- 文件名即头像 id。**推荐数字命名**：`01.png`、`02.png`、`03.png` …
- 若用数字：**从 01 开始**（避免 0，0 在很多系统里是 falsy）；**固定宽度零填充**（两位 `01`~`24` 够用，便于排序和一眼看出上限）。
- 也接受语义命名，全小写、用下划线，例：`knight.png`、`dragon.png`。
- 不要用中文、空格、大写、特殊符号。
- 扩展名固定 `.png` 或 `.webp`（混合可以，代码按文件名引用）。

建议凑齐 **16~24 个**，覆盖中世纪奇幻常见意象：骑士、国王、法师、盗贼、商人、刺客、龙、城堡、宝箱、皇冠、骷髅、乌鸦、剑盾、卷轴、水晶球、月相等。

## 引用方式

代码中通过路径 `/avatars/{文件名}` 引用（Vite 会把 `public/` 下的文件原样拷到产物根）。例如 `public/avatars/knight.png` → 渲染为 `/avatars/knight.png`。

## 实现状态

- 目录已建好，你把搜集的图片放进 `client-react/public/avatars/` 即可。
- 后续代码会自动扫描此目录、生成可选列表、存用户选择到 DB（`avatar_type='preset'`, `avatar_ref='knight'`）。
- 自定义上传头像走另一条路（`server/data/avatars/{userId}.webp`，sharp 处理），与本目录无关。
